# Concept stimulus: the "before you stop" sheet

Show this only in section 9 of the interview. Sketch it on paper or in Figma. Use the placeholder values below,
**never the participant's real numbers**.

```
┌─────────────────────────────────────────┐
│  Before you stop this SIP               │
│                                         │
│  Your plan                              │
│  Goal you set: Emergency fund · 5 years │
│  Started: March 2026 · 8 instalments    │
│                                         │
│  So far                                 │
│  Invested: ₹16,000                      │
│  Recent instalments bought more units   │
│  because prices were lower.             │
│                                         │
│  If you stop                            │
│  No new instalments from next month.    │
│  Money already invested stays invested. │
│                                         │
│  Other options                          │
│  ( ) Lower the amount                   │
│  ( ) Skip next month only               │
│  ( ) Change the debit date              │
│                                         │
│  [ Keep my choice: stop SIP ]           │
│                                         │
│  Information only — not investment      │
│  advice.                                │
└─────────────────────────────────────────┘
```

**Brief constraints, to check against while sketching**
- No fund recommendation or fund comparison.
- No fear, FOMO or urgency: no red numbers, countdowns, "you'll lose…" wording or "others are staying" pressure.
- Stopping stays one tap away and is treated as a valid choice.
